## 2. En önemli sonuç: CV↔LB kalibrasyonu ÇALIŞIYOR

```
yaz25 test-agirlikli CV   0,99715
gercek LB                 1,03910
fark                      +0,042
```

Dün gece **+0,039** öngörmüştüm (çapa +0,029 artı seçim iyimserliği +0,010).
Gerçek +0,042.

**Bunun anlamı:** on gün boyunca CV'ye bakarak karar verilebilir. Gece
boyunca reddedilen on altı yapılandırmanın hepsi doğru reddedilmiş.

Dolaylı olarak **sızıntı olmadığını** da doğruluyor: sızıntı olsaydı CV
gerçekçi olmayan biçimde iyi, LB kötü çıkardı — dün v2/v7'de tam bu
olmuştu (CV ~1,06 → LB ~1,17). Şimdi CV 1,05 → LB 1,04, tutarlı.

**Öngörü formülü:** `LB ≈ yaz25_CV + 0,042`

### Neden hedef tabanı başarısız — ders

Bir ofset iki şey yapar: koşullandırmayı iyileştirir (kazanç) ve
**katsayıyı 1'e çiviler** (bedel). Regresyon `log1p(y) = a + b·taban`:

```
log1p(guc)   b = 0,974 / 1,023 / 1,196   bedel 0,0113   <- kazanc > bedel
t_log_ort    b = 0,901 / 0,858 / 0,980   bedel 0,0434   <- bedel > kazanc
```

**Bir ofsetin bedava olup olmadığının testi tek satır: `b ≈ 1` mi?**
