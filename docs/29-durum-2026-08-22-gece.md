İki belirsizlik: **A** = v23'ün soğuk ağırlığı doğru mu (~%50),
**B** = hedge tutuyor mu (~%75). Hangisinin elenmesi en ucuz:

```
v23      A iyi,  B kotu        %12,5    0,0037      0,00046
v20+h    A kotu, B iyi         %37,5    0,0025      0,00094
v23+h    A iyi,  B iyi         %37,5    0,0025      0,00094
```

| dosya | taban | hedge | yaz25 CV | LB öngörüsü |
|---|---|---|---|---|
| `tuketim_v25_hedge.csv` | v23 | var | 0,97558 | **1,0157** |
| `tuketim_v23.csv` | v23 | yok | 0,97558 | **1,0182** |
| `tuketim_v26_v20hedge.csv` | v20 | var | 0,98863 | **1,0287** |

Üçü de doğrulandı: 714.688 satır, id sırası `sample_submission` ile birebir,
NaN/negatif yok, hedge'li dosyalarda tam-sıfır satır 0.

**Ne öğreniyoruz:**

```
v25 - v23        -> hedge'in etkisi, KUSURSUZ IZOLE (ayni 8.748 satir)
v26 vs v25       -> soguk agirlik sorusunun cevabi
v26 - hedge      -> v20'nin ortuk skoru -> kalibrasyon ucuncu kez sinanir
```

**Kabul edilen tek risk:** A ve B'nin ikisi de yanlışsa düz `v20` (1,0312)
birinciliği alırdı, `v26` (en kötü 1,0324) almazdı — %12,5'lik senaryo.
Ama hedge'in en kötü hali iki bağımsız ölçümün ikisinin de yanılmasını
gerektiriyor; gerçekçi kötü hal hedge'in **nötr** kalması, o durumda
`v26 ≈ v20`. Takas kabul edildi.

### Sonuçlar nasıl okunacak

**`v20` geldiğinde:** kalibrasyon (`LB ≈ yaz25_CV + 0,0423`) üçüncü kez
sınanır. 1,029–1,033 aralığındaysa çapa sağlam.

**`v23` geldiğinde:**

| gelen | anlamı | sıradaki |
|---|---|---|
| ≤ 1,022 | yaz25 haklı — soğuk harman değişikliği tuttu | ağırlığı koru, hedge'i v23'e uygula |
| 1,025–1,032 | kısmen | v20 ile farkı küçük, iyisini seç, hedge'i ona uygula |
| > 1,035 | kis26 haklıydı — geri al | `REJIM_AYARLARI["soguk"]["agirlik"]` → 3/1/1; hedge'i v20'ye uygula |

**Hedge geldiğinde:** tabanıyla farkı doğrudan hedge'in değeridir.

| fark | anlamı | sıradaki |
|---|---|---|
| −0,002 … −0,004 | ölçüm tuttu | kalıcı yap, sonraki her dosyaya uygula |
| −0,001 … 0 | zayıf ama zararsız | uygula, tabanları yeniden ölçme |
| > 0 | diriliş analogu yanılttı | geri al, `KOVALAR`'ı yeniden ölç |

### Prob (yarına kalan)

`S0` = taban skoru, `S1` = prob skoru, `δ` = 0,10 olmak üzere

```
E[r] = (S0² + δ² − S1²) / (2δ)        optimal kayma = E[r]
yeni dosya:  pred' = expm1(log1p(pred) + E[r])
kazanc: MSE −E[r]²  ->  RMSLE yaklasik −E[r]²/(2·S0)
```
