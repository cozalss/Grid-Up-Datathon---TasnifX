## 2. Yöntem — LB cebiri

Tahminler `p = log1p(tuketim)` uzayında. Gerçek `y` bilinmiyor ama her ölçülmüş
skor bir denklem veriyor:

```
m_j = ||p_j - y||²/N = m0 + Q_j - 2·L_j        Q_j = ||d_j||²/N ,  d_j = p_j - p_taban
                                                L_j = <r, d_j>/N ,  r = p_taban - y
=>  L_j = (m0 + Q_j - m_j)/2                    <- OLCULMUS skordan CIKAR
```

Harman `p(k) = p_taban + Σ k_j d_j` için:

```
MSE(k) = m0 - 2k'L + k'Gk        G_ij = <d_i,d_j>/N
k*     = G⁻¹L                    MSE* = m0 - L'G⁻¹L
```

**Bir yönün katkısı `L²/Q = <r, d/|d|>²` — ÖLÇEKTEN BAĞIMSIZ.** Yalnız yönün
gerçek artıkla yaptığı **açıya** bağlı. Kalite ölçütü `r = L/√Q`.

**Ölçülmüş kaliteler:** `v101` 0,1243 · `m4` 0,0641 · `g7` 0,0546 · `p51` 0,0493

**Yönler dik olduğu sürece kazançlar toplanır.** Ters korelasyonlu yönler
**süper-toplamsaldır** (bkz. §5).

## 8. Ölçüm hassasiyeti — her karar bunun altında

```
gerceklesen_MSE - ongorulen_MSE = 0,2770·(Qw_tum - Qw_pub) + 0,3252·(Qc_tum - Qc_pub)
```

`Q` tüm 714.688 satırda ölçülüyor, LB skorları **public %50**'de.
Bu kanalın sd'si **9,28e-5 RMSLE**.

> **2e-4'ün altındaki kazanç ölçüm gürültüsünden ayırt edilemez — hak harcanmaz.**

**Aşırı uyum bağlayıcı DEĞİL:** parça başına beklenen private kaybı `4·m0/N`
= 2,82e-6 RMSLE; tehlike eşiği ~43 parça. Bağlayıcı kısıt **gönderim sayısı**.

**Yön seçerken KURTOZA bak** — yüksek kurtoz, `Q`'nun az satırdan gelmesi
demek, public/private sapması büyür.

**`v101` felaketinin gerçek sebebi bu kanaldı** — yuvarlama değil.
Null yönlerde 14σ ihlal ölçüldü; `|w|` ile **karesel** büyüyor.
Bu yüzden `|w|₁ ≤ 3–5` bandı dışına çıkılmaz.

**Öngörü hatası `|k|` ile değil YER DEĞİŞTİRME ile büyüyor**
(kor +0,75 vs +0,30). Doğrulanmış bölge: yer değiştirme ≤ 0,286.
